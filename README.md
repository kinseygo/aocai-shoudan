# 澳彩收单系统

澳门六合彩（澳彩）收单管理软件简易版。

支持客户押注管理、数字/生肖/波色押注入录、开奖自动结算、备份恢复等功能。

## 功能特点

- **客户管理**：每人独立押注、中奖、应收/应付统计
- **押注入录**：01-49 数字网格 + 12 生肖 + 红蓝绿波色
- **开奖结算**：录入特码后一键自动计算
- **结算规则**：
  - 中奖金额 = 押注金额 × 47
  - 应收/应付 = 总押注 − 总中奖（正数应收，负数应付）
  - 个人客户不计算佣金（佣金仅全局统计）
- **汇总统计**：总押注、总中奖、总应收应付、全局佣金 3%
- **数据备份/恢复**：支持 SQLite 一键备份与恢复

## 环境要求

- Python 3.8+
- Flask
